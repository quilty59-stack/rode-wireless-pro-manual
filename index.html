Mode d'emploi

Guide simplifié pour formateurs

1

Allumer et éteindre

Chaque appareil (TX et RX) possède un bouton unique Ø.

  • Allumer : Appui long (~1 s) sur Ø
  • Éteindre : Appui long à nouveau
Les TX s’éteignent automatiquement après 15 min s’ils ne sont pas connectés.
2

Appairage

Automatique : Allumez RX + TX en même temps → connexion automatique.

Manuel :

  1. Allumez tous les appareils
  2. Sur RX → navigation droite jusqu’à l’écran TX
  3. Appui long sur navigation droite → « PAIR TX NOW »
  4. Sur TX → appui court sur Ø (LED bleue clignote puis fixe)
3

Enregistrement embarqué

Le son est enregistré directement sur les TX (32 Go, 32-bit float).

  • Démarrer : Bouton REC sur le dessus du TX → LED rouge allumée
  • Arrêter : Appuyer à nouveau → LED éteinte
Récupération : placez les TX dans l’étui de charge + USB-C vers ordinateur (ou RØDE Central).
4

Bluetooth & Direct Connect

Casque : Utilisez un casque filaire sur la sortie 3,5 mm du RX.

Direct Connect (iPhone uniquement) :

  1. Mettez à jour le firmware via RØDE Central
  2. Ouvrez RØDE Capture → Direct Connect
  3. Allumez uniquement les TX (pas le RX)
  4. Sélectionnez les TX dans l’app
  5. LED chaîne (∞) → bleue clignotante puis violette fixe

Conseils pratiques

Pour une utilisation optimale

🔋

Charge & transport

Rangez toujours les appareils dans l’étui de charge intelligent. Il protège et recharge le système.

💻

Réglages avancés

Utilisez RØDE Central (ordinateur) ou RØDE Capture (iOS) pour le gain, GainAssist, timecode, timeout, etc.
